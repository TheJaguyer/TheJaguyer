## About Me

I'm a full-stack software engineer and technical lead based in the Pacific Northwest. I build and architect web applications, backend services, and data pipelines, and I enjoy mentoring other engineers along the way.

Before software, I served as an Army officer and studied physics at West Point. I bring that same mission-first, detail-oriented mindset to engineering.
